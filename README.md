# 課堂遊戲 · Jogos de aula

中葡職業技術學校電子白板用的兩隊搶答遊戲：教室分紅藍兩隊，同時作答同一題，答對的一方在遊戲裡得到好處。

**開始：<https://jinnamcyber.github.io/jogos-de-aula/>** —— 先選遊戲，再選題庫。

| 遊戲 | 答對之後 | 怎樣贏 |
|---|---|---|
| 拔河 | 拉繩子 | 繩結拉過線 |
| 立體井字 | 在 3×3×3 棋盤擺一子 | 任何方向連成三個 |
| 炸彈傳遞 | 把炸彈丟給對方 | 引信燒完時炸彈不在你手上 |
| 翻轉棋 | 下一子、翻對方的棋 | 棋多者勝 |
| 賓果對決 | 叫一個號 | 自己的卡先連成一線 |
| 蛇梯賽跑 | 擲骰前進 | 先衝過終點 |

題庫：葡語分音節 120 題（初一，12 單元）· TIMSS 小四數學 60 題 + 科學 60 題。

每個遊戲頁都是單一 HTML 檔（圖片、音效內嵌），下載到白板電腦也能離線用。白板要開多點觸控；老師快捷鍵：左隊 1 2 3 4、右隊 Z X C V，空白鍵下一題，F 全螢幕。
