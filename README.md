# 課堂遊戲 · 小四數學 × 科學

中葡職業技術學校電子白板用的兩隊搶答遊戲：教室分紅藍兩隊，同時作答同一題，答對的一方在遊戲裡得到好處。
題目按 TIMSS 認知領域（知道／應用／推理）分層，配合科普潛能班進度。

**開始：<https://jinnamcyber.github.io/jogos-de-aula/>**

| 遊戲 | 答對之後 | 怎樣贏 |
|---|---|---|
| 搶答拔河 | 拉繩子，推理題拉兩格 | 繩結拉過線 |
| 立體井字 | 在 3×3×3 棋盤擺一子 | 任何方向連成三個 |
| 炸彈傳遞 | 把炸彈丟給對方 | 引信燒完時炸彈不在你手上 |
| 翻轉棋 | 下一子、翻對方的棋 | 棋多者勝 |
| 賓果對決 | 叫一個號 | 自己的卡先連成一線 |
| 蛇梯賽跑 | 擲骰前進 | 先衝過終點 |

每個遊戲頁都是單一 HTML 檔（圖片、音效內嵌），下載到白板電腦也能離線用。白板要開多點觸控；老師快捷鍵：左隊 1 2 3 4、右隊 Z X C V，空白鍵下一題，F 全螢幕。
出過的題 14 天內不重出，紀錄存在該瀏覽器；白板固定用同一個瀏覽器開同一個網址，記憶才會累積。
